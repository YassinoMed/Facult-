# ST-12 — 05 · Accessibilité et responsive

Conservés : aria-labels, aria-live, focus-visible, navigation clavier native, responsive grids, prefers-reduced-motion, aria-expanded/aria-controls sur les dialogues existants.

Ajout : bandeau budget contrasté (ambre-900/50) avec icône + texte souligné (non dépendant de la seule couleur).

Réserve : audit d'accessibilité approfondi (lecteur d'écran, contrastes systématiques) → campagne UX dédiée (R-07).
